# R01 — Environnement Windows

Sous-tâches de la story R01 du [sprint S0-R](../SPRINT-00R-SCRUM.md). Lire le [contrat de travail de l’agent](../AGENT-TASKS.md) avant exécution. Ces fiches sont des plans, pas des travaux réalisés.

**Une invocation = une seule sous-tâche.** Le titre de story R01 ne constitue pas une autorisation de tout réaliser en une fois. Les contrôles communs et critères de la story restent applicables.

## R01.01

**Titre de commit proposé :** docs(dev): record the Windows starter baseline

- **Entrée :** Aucune.
- **Travail limité :** Relever le commit, PHP x64 et extensions, Node, pnpm et les versions verrouillées ; corriger uniquement la matrice et le guide de démarrage.
- **Validation exigée :** La matrice distingue versions observées, cibles et inconnues ; aucun secret ou diagnostic supposé réussi.
- **Hors périmètre :** Aucune installation, mise à jour de dépendances ou modification de base.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.
