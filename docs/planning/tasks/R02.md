# R02 — Isolation avant migration

Sous-tâches de la story R02 du [sprint S0-R](../SPRINT-00R-SCRUM.md). Lire le [contrat de travail de l’agent](../AGENT-TASKS.md) avant exécution. Ces fiches sont des plans, pas des travaux réalisés.

**Une invocation = une seule sous-tâche.** Le titre de story R02 ne constitue pas une autorisation de tout réaliser en une fois. Les contrôles communs et critères de la story restent applicables.

## R02.01

**Titre de commit proposé :** fix(db): scope local database provisioning to Orya

- **Entrée :** R01.04 + accès administrateur PostgreSQL.
- **Travail limité :** Adapter le provisionnement à la racine et aux quatre environnements ; prévoir rôles séparés, reprise partielle et refus d’écrasement ; préparer la validation avant toute création autorisée.
- **Validation exigée :** Bases dédiées créées si accès disponible ; privilèges effectivement vérifiés ; base préexistante préservée. Sans accès, ticket bloqué et aucune création revendiquée.
- **Hors périmètre :** Ne pas basculer la base active ni modifier les bases d’autres projets.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.

## R02.02

**Titre de commit proposé :** fix(test): guard database resets and fixture seeding

- **Entrée :** R02.01.
- **Travail limité :** Contrôler environnement, driver, base résolue et rôle avant nettoyage ou seeding ; protéger aussi le lancement direct de E2eSeeder.
- **Validation exigée :** Les cibles dev, rôle inattendu et URL de connexion incohérente sont refusées avant mutation ; contrôle positif sur cible isolée.
- **Hors périmètre :** Ne pas lancer l’ensemble E2E ni réinitialiser les comptes existants.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.

## R02.03

**Titre de commit proposé :** test(e2e): isolate fixture and server environments

- **Entrée :** R02.02.
- **Travail limité :** Affecter aux E2E base, ports, cookies et processus propres ; propager la même configuration au seeder et aux serveurs ; empêcher la réutilisation du serveur dev.
- **Validation exigée :** Un serveur étranger déjà actif n’est pas adopté ; configuration de tous les processus concordante ; l’exécution des parcours attend R03.02.
- **Hors périmètre :** Pas de modification des comportements Fortify ou de bascule dev.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.
