# R03 — Transition PostgreSQL

Sous-tâches de la story R03 du [sprint S0-R](../SPRINT-00R-SCRUM.md). Lire le [contrat de travail de l’agent](../AGENT-TASKS.md) avant exécution. Ces fiches sont des plans, pas des travaux réalisés.

**Une invocation = une seule sous-tâche.** Le titre de story R03 ne constitue pas une autorisation de tout réaliser en une fois. Les contrôles communs et critères de la story restent applicables.

## R03.01

**Titre de commit proposé :** docs(db): record SQLite retention and cutover decisions

- **Entrée :** R02.03 + décision sur les données.
- **Travail limité :** Inventorier les données sans les exposer, produire une sauvegarde cohérente protégée et consigner conservation ou abandon confirmé ; choisir la branche décrite dans POSTGRES-TRANSITION.
- **Validation exigée :** Sauvegarde identifiée, contenu qualifié, décision propriétaire tracée ; si doute, activer les trois tickets D avant R03.03.
- **Hors périmètre :** Ne jamais supprimer SQLite, transférer les données ou régénérer APP_KEY dans ce ticket.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.

## R03.02

**Titre de commit proposé :** fix(db): validate the starter schema on PostgreSQL

- **Entrée :** R03.01.
- **Travail limité :** Configurer une cible isolée PostgreSQL et Pest ; appliquer les migrations du starter et corriger seulement les incompatibilités démontrées ; vérifier contraintes, emails, JSON et séquences.
- **Validation exigée :** Migration initiale et seconde passe réussies ; tests PostgreSQL de contraintes et données typées ; table sessions conservée ; aucune retombée vers SQLite dans cette suite.
- **Hors périmètre :** Pas de bascule du développement, de transfert de comptes ni de conversion globale en UUID.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.

## R03.03

**Titre de commit proposé :** fix(db): switch the active development environment to PostgreSQL

- **Entrée :** R03.02 + R03.D3 si données conservées.
- **Travail limité :** Basculer configuration et préparation locales vers la cible validée ; traiter les données selon décision ; rafraîchir les caches et redémarrer les seuls processus nécessaires.
- **Validation exigée :** Inscription/login persistants sur PostgreSQL ; contrôle de la base effective ; source préservée ; traitement des données réconcilié si applicable.
- **Hors périmètre :** Pas de déploiement distant, de passage des sessions à Redis ou de nettoyage automatique de la source.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.

Les trois tâches suivantes s’intercalent entre R03.02 et R03.03 uniquement si des données doivent être conservées. Elles sont à estimer séparément ; en cas d’abandon confirmé des seules données de démonstration, les marquer « non applicable » avec justification, jamais « réalisé ».

## R03.D1 — Conditionnel : données à conserver

**Titre de commit proposé :** feat(db): add a repeatable SQLite data transfer

- **Entrée :** R03.02 + conservation confirmée.
- **Travail limité :** Définir puis réaliser le transfert vers une copie PostgreSQL isolée ; préserver IDs, hashes, facteurs 2FA chiffrés et credentials passkeys ; gérer l’interruption/reprise.
- **Validation exigée :** Essai reproductible sur copie ; aucune donnée importée deux fois ; aucune mutation de la source ; clés nécessaires disponibles par canal sûr.
- **Hors périmètre :** Pas de bascule active ni d’invalidation de sessions réelles.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.

## R03.D2 — Conditionnel : données à conserver

**Titre de commit proposé :** test(db): reconcile imported identities and credentials

- **Entrée :** R03.D1.
- **Travail limité :** Comparer décomptes, références et séquences ; vérifier login, 2FA et passkey d’un compte témoin ; traiter les collisions identifiées.
- **Validation exigée :** Rapport sans secret ; intégrité et facteurs d’authentification vérifiés ; création post-import sans collision.
- **Hors périmètre :** Pas de normalisation destructive automatique ou de changement de domaine WebAuthn.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.
