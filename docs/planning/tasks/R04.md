# R04 — Identité par parcours

Sous-tâches de la story R04 du [sprint S0-R](../SPRINT-00R-SCRUM.md). Lire le [contrat de travail de l’agent](../AGENT-TASKS.md) avant exécution. Ces fiches sont des plans, pas des travaux réalisés.

**Une invocation = une seule sous-tâche.** Le titre de story R04 ne constitue pas une autorisation de tout réaliser en une fois. Les contrôles communs et critères de la story restent applicables.

## R04.01

**Titre de commit proposé :** test(auth): preserve the starter journeys on PostgreSQL

- **Entrée :** R03.03.
- **Travail limité :** Faire passer les huit E2E existants sur l’environnement isolé ; corriger seulement une régression directement démontrée, sans modifier les attentes pour la masquer.
- **Validation exigée :** Huit tests existants réussis ; si plusieurs causes indépendantes apparaissent, ouvrir des sous-tickets avant corrections multiples.
- **Hors périmètre :** Pas de nouveaux parcours métier ni de désactivation 2FA/passkeys.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.

## R04.02

**Titre de commit proposé :** test(auth): enforce API authentication and CSRF boundaries

- **Entrée :** R04.01.
- **Travail limité :** Tester les accès API invités, le cookie invité, CSRF par vrai HTTP, logout et absence de données sensibles ; limiter les corrections aux frontières concernées.
- **Validation exigée :** API protégée inaccessible sans identité ; requête mutante sans preuve CSRF refusée ; ancien cookie invalide après logout.
- **Hors périmètre :** Pas de SSO OIDC, changement global des erreurs ou nouveau proxy.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.

## R04.03

**Titre de commit proposé :** test(sessions): verify account isolation and revocation

- **Entrée :** R04.02.
- **Travail limité :** Tester deux utilisateurs et deux appareils, lecture/révocation limitée au propriétaire et expiration réelle ; conserver les sessions PostgreSQL.
- **Validation exigée :** Un compte ne consulte/révoque pas celles d’un autre ; appareil révoqué refusé ; session courante conforme à la règle prévue.
- **Hors périmètre :** Pas de refonte du stockage des sessions.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.

## R04.05

**Titre de commit proposé :** test(2fa): reject invalid and replayed authentication factors

- **Entrée :** R04.04.

- **Validation exigée :** Codes invalides refusés, code consommé non réutilisable ; activation/désactivation protégées.
- **Hors périmètre :** Ne pas modifier le mécanisme cryptographique du framework.

## R04.06
