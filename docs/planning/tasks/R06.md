Sous-tâches de la story R06 du [sprint S0-R](../SPRINT-00R-SCRUM.md). Lire le [contrat de travail de l’agent](../AGENT-TASKS.md) avant exécution. Ces fiches sont des plans, pas des travaux réalisés.

**Une invocation = une seule sous-tâche.** Le titre de story R06 ne constitue pas une autorisation de tout réaliser en une fois. Les contrôles communs et critères de la story restent applicables.

## R06.01

**Titre de commit proposé :** ci(quality): align runtime and static checks

- **Entrée :** R05.04.
- **Travail limité :** Adapter le workflow qualité : versions validées, pnpm figé, politique de dépendances, Pint, lint, format et typage séparé.
- **Validation exigée :** Installation propre et contrôles statiques réussis ; défaillance détectée sans bypass.
- **Hors périmètre :** Ne pas modifier les workflows d’intégration/E2E ni mettre à jour tout le framework.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.

## R06.02

**Titre de commit proposé :** ci(test): run integration tests on native PostgreSQL and Redis

- **Entrée :** R06.01.
- **Travail limité :** Adapter le workflow Pest avec services Linux natifs isolés, PostgreSQL 17 et Redis ; conserver les gardes avant fixtures.
- **Validation exigée :** Job CI identifié exécutant les tests DB/worker réels ; aucun SQLite utilisé comme preuve d’intégration.
- **Hors périmètre :** Pas de conteneurs, de secrets dev copiés en CI ou de déploiement.
- **Sortie :** résultat et preuve consignés dans le TODO ; commit limité à cette tâche si la création de commits est autorisée ; arrêter la session de travail sur ce ticket, sans commencer le suivant.
